# FINSAFE KZ — образовательная платформа по финансовой безопасности

Фронтенд образовательной платформы о финансовой безопасности и профилактике мошенничества в Казахстане: игры на распознавание схем обмана, короткие курсы с итоговым тестом, чемпионат с рейтингами и достижениями, медиалента и профиль с прогрессом.

Это этап 1–2 по ТЗ: готовый интерфейс и рабочая игровая/учебная логика на моковых данных. Бэкенда нет — вся «серверная» логика имитируется слоем `/src/api`, который спроектирован так, чтобы его можно было подключить к реальному FastAPI без переписывания компонентов.

## Стек

- Vite + React 18 + TypeScript (strict)
- Tailwind CSS (дизайн-токены — в `tailwind.config.js`)
- React Router v6
- react-i18next (ru / kk, выбор языка хранится в `localStorage`)
- lucide-react, framer-motion (лёгкие анимации), react-helmet-async

## Запуск

```bash

npm run dev
```

Приложение поднимется на `http://localhost:5173`.

## Где менять контент (моки)

Весь контент — курсы, уроки, игры, вопросы, рейтинги, публикации — лежит в `/src/mocks/*.ts`:

- `games.ts` — сценарии всех 4 игр (`scam-or-not`, `detective`, `dropper`, `pyramid`), каждый шаг — объект `GameStep` с текстом на ru/kk, вариантами ответов и объяснением.
- `courses.ts` — курсы Академии: уроки по структуре (цель → объяснение → материал → пример → интерактивный вопрос → вывод) и итоговый тест.
- `championship.ts` — таблицы лидеров по областям (`week`/`month`/`season`/`teams`/`institutions`), турниры, достижения.
- `media.ts` — публикации медиаленты.

Компоненты и страницы **никогда не импортируют эти файлы напрямую** — только через `/src/api/*.ts`. Чтобы добавить новый курс/игру/публикацию, достаточно дополнить соответствующий мок — остальное подхватится автоматически (фильтры, карточки, каталоги).

## Как подключить реальный API (FastAPI)

Каждый файл в `/src/api/` сейчас просто возвращает моковые данные с имитацией сетевой задержки (`withDelay`, 200–400 мс):

```ts
// src/api/coursesApi.ts
async function getCourses(): Promise<Course[]> {
  return withDelay(cloneValue(courses))
}
```

Чтобы подключить бэкенд, нужно заменить тело функций на `fetch`/`axios`-запросы к FastAPI, сохранив те же сигнатуры (имена функций, типы параметров и возвращаемых значений из `/src/types`):

```ts
async function getCourses(): Promise<Course[]> {
  const res = await fetch('/api/courses')
  return res.json()
}
```

Поскольку все страницы и компоненты обращаются только к объектам `gamesApi`, `coursesApi`, `leaderboardApi`, `mediaApi`, `progressApi`, UI менять не придётся — только файлы в `/src/api`.

Отдельный случай — `progressApi.ts`: сейчас прогресс пользователя (пройденные уроки, результаты игр, достижения, профиль) хранится в `localStorage`. При подключении бэкенда эти функции нужно заменить на запросы к серверу (с авторизацией), оставив интерфейс прежним.

## Локализация

Все строки интерфейса — в `src/i18n/ru.json` и `src/i18n/kk.json` (ключ в ключ, одинаковая структура). Текст в JSX не хардкодится — только через `useTranslation()` / `t('...')`. Для локализованного контента из моков (заголовки курсов, вопросы игр и т.д.) используется тип `LocalizedText` (`{ ru, kk }`) и хук `useLocalizedText()`.

## Прогресс пользователя

`progressApi` хранит в `localStorage` (ключ `finsafe.progress.v1`): пройденные уроки, результаты итоговых тестов, попытки игр, разблокированные достижения и профиль (псевдоним, цвет аватара). Чтение/запись обёрнуты в `try/catch` — если `localStorage` недоступен, приложение продолжает работать без сохранения прогресса.

## Что не реализовано (следующий этап)

Регистрация, админка, реальный бэкенд, генерация PDF-сертификата — сознательно оставлены за рамками этого этапа.
